# Early Prediction of HIV Treatment Failure Using Longitudinal Clinical Data

## About the Project

This project aims to investigate the early prediction of HIV treatment failure using longitudinal clinical data and machine learning.

By analysing changes in clinical indicators such as CD4 count, viral load, and ART-related information over time, the project seeks to identify patterns associated with future virological treatment failure.

The project will also explore Explainable AI (XAI) techniques, including SHAP, to improve the interpretability of model predictions.

## Objectives

- Analyse longitudinal HIV clinical data.
- Develop meaningful temporal features from repeated patient visits.
- Investigate suitable machine learning models for early risk prediction.
- Evaluate model performance using appropriate metrics.
- Interpret predictions using SHAP.

## Dataset

The project is investigating longitudinal data from the Multicenter AIDS Cohort Study (MACS) and the Women's Interagency HIV Study (WIHS).

Dataset selection, harmonization, and the operational definition of treatment failure are still under investigation.

Raw participant-level data will not be uploaded to this repository.

## Proposed Technology Stack

- Python
- pandas and NumPy
- scikit-learn
- XGBoost and LightGBM
- SHAP
- Matplotlib

## Project Status

Currently in the dataset assessment and methodology development phase. Model training and evaluation are yet to be completed.
